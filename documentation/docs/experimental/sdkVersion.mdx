# sdkVersion

::: info

Please use [the version of this property in `fastly:runtime` instead](../runtime/sdkVersion.mdx), as `fastly:experimental` is deprecated.

:::

The read-only **`sdkVersion`** property is a string whose indicates what JavaScript SDK version is being used.

## Value

A string value.
